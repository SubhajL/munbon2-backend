═══════════════════════════════════════════════════════════════════════════

🔍 ROOT CAUSE IDENTIFIED:
   - 4,738 node_modules directories in ~/dev
   - 2,584 directories modified in last 24 hours
   - Spotlight trying to index millions of files
   - Causing sustained 60%+ CPU usage

📊 IMPACT:
   - Continuous disk I/O
   - Memory pressure
   - CPU saturation
   - Heat generation

✅ SOLUTION:

Step 1: Exclude node_modules from Spotlight
----------------------------------------
Run this command to exclude all node_modules:

find ~/dev -type d -name "node_modules" -exec mdfind -onlyin {} \; 2>/dev/null | \
while read dir; do
    echo "Excluding: $dir"
    defaults write com.apple.SpotlightServer.plist ExcludedPaths -array-add "$dir"
done

# OR use this simpler method:
echo "~/dev/**/node_modules" >> ~/.config/spotlight-exclude.txt

# Then reload Spotlight:
sudo mdutil -E /

Step 2: Add .gitignore directories to Spotlight exclusions
----------------------------------------
# Common directories to exclude:
- **/node_modules
- **/.next
- **/dist
- **/build
- **/.venv
- **/venv
- **/__pycache__
- **/.pytest_cache

Step 3: Rebuild Spotlight Index (CLEAN START)
----------------------------------------
# WARNING: This will delete and rebuild your entire Spotlight index
# Only do this after excluding node_modules

sudo mdutil -E /
sudo mdutil -i on /

# This will take 1-2 hours but will fix the issue permanently
