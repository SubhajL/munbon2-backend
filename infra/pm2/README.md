# PM2 Infrastructure - Irrigation Canal Services

This directory contains PM2 ecosystem configuration for managing irrigation canal services on resource-constrained hosts.

## Files

- **`build-irrigation-config.ts`** - TypeScript module that generates PM2 process configurations
- **`ecosystem-irrigation.config.js`** - PM2 ecosystem file (requires compiled JS in `dist/`)
- **`__tests__/build-irrigation-config.spec.ts`** - Unit tests for configuration builder
- **`dist/`** - Compiled JavaScript output (generated by `npm run build`)

## Usage

### Build Configuration
```bash
npm install
npm run build
```

### Run Tests
```bash
npm test
```

### Verify (Type Check + Tests)
```bash
npm run verify
```

### Start Services with PM2
```bash
# From repository root
pm2 start infra/pm2/ecosystem-irrigation.config.js

# Check status
pm2 list

# View logs
pm2 logs
```

## Services Managed

1. **flow-monitoring** (Python) - Port 3011
2. **scheduler** (Python) - Port 3012
3. **bff-water-planning** (Python) - Port 3002
4. **ros-gis-integration** (Python) - Port 3047
5. **awd-control** (Node.js) - Port 3010

## Architecture

### `buildProcessConfig(spec: ServiceSpec): PM2ProcessConfig`

Normalizes service specifications into PM2-ready process configurations.

**Parameters:**
- `spec.name` - Service name (matches directory in `services/`)
- `spec.type` - Either `'python'` or `'node'`
- `spec.port` - Port number for the service
- `spec.script` - Entry point script
- `spec.args` - Optional command-line arguments
- `spec.env` - Optional environment variables

**Returns:**
PM2ProcessConfig with:
- Correct working directory (`services/<name>`)
- Interpreter set for Python services
- Log paths in repository `logs/` directory
- Auto-restart enabled
- Memory limits (512M for Python, 256M for Node.js)
- Graceful shutdown hooks

**Example:**
```typescript
const config = buildProcessConfig({
  name: 'bff-water-planning',
  type: 'python',
  port: 3002,
  script: './venv/bin/python',
  args: '-m uvicorn src.main:app --host 0.0.0.0 --port 3002',
});
```

### `getIrrigationProcesses(): PM2ProcessConfig[]`

Returns array of PM2 process configurations for all 5 irrigation canal services.

**Returns:**
Array of 5 PM2ProcessConfig objects with default environment variables and settings.

**Example:**
```typescript
const processes = getIrrigationProcesses();
// [
//   { name: 'flow-monitoring', ... },
//   { name: 'scheduler', ... },
//   { name: 'bff-water-planning', ... },
//   { name: 'ros-gis-integration', ... },
//   { name: 'awd-control', ... }
// ]
```

## Environment Variables

Each service has default environment variables defined in `build-irrigation-config.ts`. To customize:

1. Edit `build-irrigation-config.ts`
2. Modify the `serviceSpecs` array in `getIrrigationProcesses()`
3. Rebuild: `npm run build`
4. Restart PM2: `pm2 restart all`

## Development

### Adding a New Service

1. Add service spec to `getIrrigationProcesses()`:
```typescript
{
  name: 'new-service',
  type: 'python', // or 'node'
  port: 3099,
  script: './venv/bin/python',
  args: '-m uvicorn src.main:app --host 0.0.0.0 --port 3099',
  env: {
    PORT: '3099',
    LOG_LEVEL: 'INFO',
    // ... other env vars
  },
}
```

2. Add test case in `__tests__/build-irrigation-config.spec.ts`

3. Rebuild and verify:
```bash
npm run build
npm run verify
```

### Modifying Service Configuration

1. Update specs in `build-irrigation-config.ts`
2. Rebuild: `npm run build`
3. Restart services: `pm2 restart all`
